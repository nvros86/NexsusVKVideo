# Roadmap
## Этап 0 — собираемый каркас
Solution, проекты, фиксированный SDK, MVVM/DI, стартовое окно, тесты Core, CI с реальной сборкой.
Готово: чистый checkout собирается; CI не пропускает отсутствие solution.

## 0.1 — оболочка и воспроизведение
Навигация, Home demo, официальный поддерживаемый VK playback путь, ошибки и browser fallback.
Готово: ручной сценарий открыть/закрыть/повторить, отсутствие утечек player, keyboard navigation.

## 0.2 — данные
Документированный поиск при доступности API, история, избранное, настройки, миграции.
Готово: offline и auth errors, отмена, сохранение после restart, тесты данных.

## 0.3 — качество
Адаптивный UI, доступность, perf measurements, упаковка, release candidate.
Готово: визуальная матрица и clean-machine smoke.

## 1.0 — стабильный выпуск
Проверенная интеграция, лицензии, release notes, процедура поддержки и откат.
AI и дополнительные провайдеры — после MVP и отдельного решения. Даты не обещаны.
