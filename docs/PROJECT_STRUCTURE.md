# Структура
Корень: README, AGENTS, старт, workflow, оптимизация, prompt, security, release, changelog.
docs/: architecture, modules, roadmap, coding style, design guide, decisions.
changes/: один файл на логическое изменение и правила отката.
assets/branding/: оригинальный логотип; assets/mockups/: графический reference.
.github/: CI, Copilot, Issue/PR templates.
src/: после этапа 0 — NexsusVKVideo.App, .Core, .Infrastructure, .Modules.
tests/: после этапа 0 — NexsusVKVideo.Core.Tests, .Infrastructure.Tests.
scripts/: проверки пакета.
Solution NexsusVKVideo.sln должен находиться в корне. Пустые рабочие папки сохраняются README-файлами.
