# Модули
| Модуль | Обязанность | Критерий готовности |
|---|---|---|
| Home | витрина и переход к видео | загрузка/пусто/ошибка, demo помечено |
| Search | запрос, отмена, страницы | старый ответ не заменяет новый |
| VideoPlayer | playback lifecycle | только один player, освобождение ресурсов |
| Library/History | история просмотра | сохранение после перезапуска, очистка |
| Favorites | локальные избранные | уникальность provider+id, удаление |
| Settings | предпочтения и приватность | валидация, восстановление default |
| AI Center | будущая точка расширения | экран «Скоро», без фоновых запросов |

Модули регистрируются явно в composition root. Отключённый модуль не регистрирует маршруты и фоновые задачи.
Общие модели принадлежат Core. Взаимодействие через контракты, а не ссылки на чужие ViewModel.
Будущие модули: AI summary, рекомендации, другие провайдеры. Каждый требует отдельной спецификации, оценки API/стоимости/приватности и тестов.
