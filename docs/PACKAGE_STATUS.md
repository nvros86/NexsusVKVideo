# Состояние пакета
Дата актуализации: 2026-09-22.
Документы восстановлены по доступной переписке, исходные Markdown-вложения не получены.
Графический макет создан заново встроенным imagegen по описанию dark premium cyan/blue neon.
Утверждённый пользователем логотип включён в assets/branding/a_sleek_high_resolution_app_icon_logo_design_on.png. Исходный файл: Изображение Codex 19 сент. 2026 г., 17_07_27.png. Содержимое сохранено без изменения; имя в пакете соответствует ранее согласованному пути.
Исполняемое приложение — минимальная WebView2-оболочка `https://vkvideo.ru/`: после запуска в окне остаётся только интерфейс официального сайта VK Video и системная рамка Windows. Поиск, каталог и авторизация выполняются сайтом VK. Верхнеуровневая навигация ограничена HTTPS-доменами VK; popup-навигация VK остаётся в том же окне. Ранее созданные Core, Infrastructure и Modules остаются в репозитории как задел, но не подключаются к стартовой UI-композиции. NexsusVKVideo не является собственным клиентом VK API и не реализует каталог или live search самостоятельно.
Публичная beta `v0.2.1-beta.1` содержит standalone EXE и Inno Setup installer; GitHub Actions повторяет restore, Release build и тесты перед публикацией assets. В исходниках тега есть MIT License, публичный скриншот и документы для участников. Подписанный выпуск требует отдельного сертификата code signing.
