# 0001 — .NET 10 LTS and fixed SDK

Дата: 2026-09-19

## Контекст

Этап 0 требует поддерживаемый стабильный .NET LTS, точную версию SDK и одинаковую локальную/CI-сборку. На дату решения [.NET 10 — активный LTS с поддержкой до 14.11.2028](https://dotnet.microsoft.com/en-us/platform/support/policy); .NET 8 заканчивает поддержку 10.11.2026. Выбранная версия SDK опубликована на [официальной странице загрузки .NET](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

## Варианты

- .NET 8 LTS: краткий оставшийся срок поддержки.
- .NET 9 STS: не LTS и заканчивает поддержку 10.11.2026.
- .NET 10 LTS: актуальный поддерживаемый LTS.

## Решение

Core, Infrastructure и Modules используют `net10.0`; WPF App использует необходимый платформенный TFM `net10.0-windows`. `global.json` и GitHub Actions закрепляют SDK `10.0.401` с `rollForward: disable`. Общие версии NuGet-пакетов находятся в `Directory.Packages.props`.

## Последствия и обратимость

Для локальной разработки требуется установленный .NET SDK 10.0.401. Изменение версии возможно отдельным решением: обновить `global.json`, центральные версии пакетов, CI и выполнить полный restore/build/test.
