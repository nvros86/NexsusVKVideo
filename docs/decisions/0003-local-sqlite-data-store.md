# 0003 — local MVP data uses one versioned SQLite database

Дата: 2026-09-19

## Контекст

Этап 0.2 требует историю, избранное и настройки, которые переживают перезапуск. Core задаёт контракты хранилищ и не должен знать об SQLite или файловой системе.

## Решение

Infrastructure реализует `IHistoryRepository`, `IFavoritesRepository` и `ISettingsStore` одним `SqliteLocalDataStore`. Файл расположен в `%LocalAppData%\NexsusVKVideo\data\nexsusvkvideo.db`, создаётся лениво при первой операции и никогда не попадает в Git.

Начальная миграция (`PRAGMA user_version = 1`) создаёт таблицы истории, избранного и настроек. Составной primary key `provider + video_id` предотвращает дубли избранного. База с версией выше поддерживаемой отклоняется: приложение не выполняет неявный downgrade данных.

## Последствия и обратимость

История и избранное доступны после перезапуска через контракт Core. Схемы будущих версий добавляются только миграцией вверх с отдельным тестом копии базы. Откат кода не понижает базу: перед rollback версии с миграцией нужно сохранить копию `%LocalAppData%\NexsusVKVideo\data`.
