# 0002 — VK playback uses the documented video widget only

Дата: 2026-09-19

## Контекст

Официальная документация VK для [Video widget](https://dev.vk.com/ru/widgets/video) показывает embed URL вида `https://vk.ru/video_ext.php?oid=…&id=…` и отдельную публичную страницу видео вида `https://vk.ru/video-…`. Это браузерный виджет, а не разрешение на получение прямых потоков, cookies или токенов.

## Решение

В App добавлен один экземпляр WebView2 с отдельным user-data каталогом в `%LocalAppData%\NexsusVKVideo\WebView2`. Инфраструктурная политика разрешает только HTTPS, точный host `vk.ru`, путь `/video_ext.php` и непустые query-параметры `oid` и `id`. Любая верхнеуровневая навигация за пределы этой формы отменяется. Внешний fallback разрешён лишь на точную публичную video-page того же host.

Home содержит исключительно заметно помеченный пример из документации VK — он нужен для проверки интеграции и не является каталогом приложения или обещанием доступности контента.

## Последствия и обратимость

Встроенный плеер показывает возможности и ограничения самого VK widget, включая необходимость авторизации или недоступность контента. Приложение не реализует OAuth в WebView2, API-каталог или прямой playback. Изменение можно откатить одним commit; пользовательский кэш WebView2 в Git не попадает.
