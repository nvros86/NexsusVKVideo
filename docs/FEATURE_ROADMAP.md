# План развития NexsusVKVideo

Этот документ фиксирует пользовательские улучшения после публичной `v0.1.0-beta.1`. Каждая строка — отдельная следующая версия: работа начинается в указанном порядке, а выпуск требует build, test, ручного smoke на Windows и записи в `CHANGELOG.md`.

| Версия | Улучшение | Критерий готовности |
|---|---|---|
| `0.1.1-beta.1` | Надёжный запуск | Есть безопасный экран ошибки, повторная загрузка и ссылка на официальный WebView2 Runtime; интерфейс VK не перекрыт при успешной загрузке. |
| `0.1.2-beta.1` | Установщик | Готово: воспроизводимый installer создаёт ярлыки, устанавливает приложение и предлагает открыть официальный WebView2 Runtime при отсутствии. Подпись не обещается без сертификата. |
| `0.1.3-beta.1` | Горячие клавиши | Готово: назад, вперёд, обновление и масштаб работают через стандартные сочетания, не меняя сайт VK. |
| `0.1.4-beta.1` | Состояние окна | Готово: безопасно сохраняются размер, позиция и развёрнутое состояние; окно возвращается в видимую область виртуального рабочего стола. |
| `0.1.5-beta.1` | Локальные данные и приватность | Пользователь может запланировать очистку профиля WebView2 с понятным предупреждением о повторном входе. |
| `0.1.6-beta.1` | Ссылки и загрузки | Определено безопасное поведение для загрузок и ссылок вне доменов VK; непроверенные схемы не выполняются. |
| `0.1.7-beta.1` | Интеграция с Windows | Проверены DPI, сон, несколько мониторов, тёмная тема и полноэкранное видео. |
| `0.1.8-beta.1` | Диагностика | Локальный отчёт о версии и Runtime без автоматической телеметрии и без секретов. |
| `0.2.0-beta.1` | Обновления | Проверка и установка обновлений с GitHub Releases, только после определения канала обновлений и модели доверия. |
| `0.3.0` | Подписанный релиз | Подписанный установщик и EXE. Требует сертификата подписи от владельца проекта; без него версия не выпускается как «подписанная». |

## Границы

- NexsusVKVideo остаётся оболочкой официального сайта VK Video, а не клиентом неофициального API.
- Вход происходит только на официальных страницах VK внутри WebView2; приложение не получает пароль, cookies или токены.
- Автообновление и подпись не реализуются до отдельного решения о канале распространения и сертификате.
