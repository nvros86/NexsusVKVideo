# Скриншоты

`NexsusVKVideo-v0.2.0-beta.1.png` — реальный снимок окна приложения версии `v0.2.0-beta.1`.

- Для снимка используется новый временный профиль WebView2, поэтому в нём нет данных входа, cookies, истории или персональных рекомендаций владельца проекта.
- Интерфейс и видеоматериалы внутри окна отрисованы официальным сайтом VK Video; NexsusVKVideo не копирует и не хранит эти данные в репозитории как собственный контент.
- Скриншот создан скриптом `scripts/Capture-WindowScreenshot.ps1`; перед новым снимком проверяйте отсутствие личных данных.
