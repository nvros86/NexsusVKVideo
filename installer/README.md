# Установщик NexsusVKVideo

`NexsusVKVideo.iss` собирается Inno Setup 7 через `scripts/Build-Installer.ps1`. Скрипт по умолчанию сам восстанавливает зависимости; параметр `-SkipRestore` предназначен только для изолированной среды после отдельного `dotnet restore`. Итоговый Setup EXE устанавливает приложение только для текущего пользователя в `%LocalAppData%\Programs\NexsusVKVideo`, поэтому не запрашивает права администратора.

Установщик проверяет Evergreen WebView2 Runtime по значениям `pv` в документированных ветках HKLM/HKCU. Если Runtime отсутствует, пользователь может выбрать переход на официальную страницу Microsoft после завершения установки. Runtime не встраивается и не загружается установщиком: Evergreen Runtime самостоятельно получает обновления от Microsoft.

Сборка и публикация installer до цифровой подписи допустимы только как beta. Перед стабильным выпуском требуется сертификат подписи и отдельная процедура подписи EXE и Setup EXE.
