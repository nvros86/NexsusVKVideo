# Релизы
Стартовый пакет не является релизом приложения.
1. Проверь завершённый milestone, чистый Git, зелёный CI для точного commit и закрытые критические ошибки.
2. Обнови единый источник версии приложения и CHANGELOG.md; перенеси Unreleased в X.Y.Z с датой.
3. Выполни Release build/tests и smoke на чистой Windows-машине; проверь WebView runtime, login/logout, данные и DPI.
4. Сформируй артефакт, проверь состав, сторонние лицензии, секреты и SHA-256. Подписание и installer требуют отдельной настройки.
5. Подготовь release notes: возможности, исправления, ограничения, prerequisites, обновление и откат.
6. При разрешённой публикации создай tag vX.Y.Z на проверенном commit и GitHub Release. Не перезаписывай опубликованный tag.
7. Для отката используй предыдущий проверенный артефакт; восстановление данных — по совместимости схемы и резервной копии. Код откатывай по changes/README.md.
