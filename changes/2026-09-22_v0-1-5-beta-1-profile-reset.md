# v0.1.5-beta.1 — управляемая очистка профиля WebView2

## Изменение

- Добавлено `Ctrl+Shift+Delete` для планирования очистки локального профиля WebView2.
- До создания маркера показывается предупреждение о выходе из аккаунта; фактическое удаление выполняется только на следующем запуске приложения.

## Безопасность и границы

- NexsusVKVideo не читает и не экспортирует cookies, пароли или токены.
- Никакие данные не отправляются по сети; пользователь сам подтверждает действие.

## Проверка

- Требуется build и автоматические тесты решения.
- Ручной smoke: нажать `Ctrl+Shift+Delete`, отменить диалог, затем подтвердить и убедиться, что после перезапуска требуется вход в VK.
