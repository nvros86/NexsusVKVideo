# Минимальная оболочка VK Video

Цель: оставить в исполняемом приложении только официальный VK Video без нативного интерфейса NexsusVKVideo.

Базовый commit: `a9cf6cf`.

Затронутые компоненты: WPF App composition root, главное окно, зависимости App и документация состояния.

Результат: `MainWindow` содержит только WebView2 и скрываемое сообщение об ошибке. App больше не создаёт view models, SQLite-хранилище, темы, demo-каталог, нативные библиотеку/избранное/настройки или дополнительный player. При запуске WebView2 открывает `https://vkvideo.ru/`; системная рамка Windows остаётся для управления окном. Удаление отложенного WebView2-профиля, установленное более ранней версией, применяется один раз при старте.

Проверки: `dotnet restore NexsusVKVideo.sln -m:1 --disable-parallel` — успешно с доступом к NuGet; изолированная Release build в `artifacts/minimal-shell-validation` — успешно, 0 warnings/0 errors; изолированные тесты — успешно, 32/32. Ручная проверка: в окне виден только официальный сайт VK Video, поиск и вход работают на стороне VK.

Миграция/совместимость: SQLite-данные прежних версий не удаляются, но больше не используются UI. Локальный профиль WebView2 и сессия VK сохраняются, если ранее не запланирована их очистка.

Откат: `git revert <commit>` для commit этого изменения, затем повторить build и test.
