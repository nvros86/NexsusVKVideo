# v0.1.6-beta.1 — безопасные ссылки и загрузки

## Изменение

- Внешнее HTTPS-окно из сайта VK может быть открыто только после подтверждения пользователя и только системным браузером.
- Загрузки разрешены только с HTTPS-доменов VK; загрузка с другого источника отменяется до стандартного диалога WebView2.

## Безопасность и границы

- HTTP и протоколы кроме HTTPS не передаются операционной системе.
- Приложение не выбирает путь для файла, не подменяет файл и не запускает загрузку.
- Поведение опирается на официальное событие WebView2 `DownloadStarting`: флаг `Cancel` отменяет загрузку до отображения диалога.

## Проверка

- Требуется build и автоматические тесты решения.
- Ручной smoke: проверить ссылку на другой сайт, отменить и подтвердить её; проверить загрузку из VK и блокировку внешнего источника.
