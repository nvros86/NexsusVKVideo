# Штатное разворачивание окна

Цель: исправить смещение окна влево при нажатии системной кнопки «Развернуть».

Базовый commit: `f6080c4`.

Затронутые компоненты: code-behind главного WPF-окна.

Результат: размеры рабочей области ограничивают только стартовый размер и минимальный размер окна. `MaxWidth` и `MaxHeight` больше не назначаются, поэтому Windows сама разворачивает окно на всю рабочую область текущего монитора.

Проверки: `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1` — успешно, 0 warnings/0 errors; `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1` — успешно, 32/32. Ручная проверка: разворачивание/восстановление окна на основном и дополнительном мониторах.

Миграция/совместимость: данных и профиля WebView2 не изменяет.

Откат: `git revert <commit>` для commit этого изменения, затем повторить build и test.
