# Этап 0.2 — UI библиотеки и избранного

Дата: 2026-09-19

Цель: подключить проверенное локальное SQLite-хранилище к WPF-экрану, не добавляя VK API или сетевых данных.

База Git: `74356de feat: add local SQLite data store`.

Компоненты: App MVVM, Home demo metadata, Library/Favorites DataTemplates, асинхронные команды.

Изменение: открытие официального demo VK widget добавляет запись в локальную историю и восстанавливает состояние избранного. В плеере работает переключатель добавления/удаления избранного. Библиотека показывает последние 100 записей, обновляется и очищается; Избранное обновляется и удаляет отдельную запись. Все I/O вызовы получают CancellationToken через управляемые async-команды. Demo-карточки без подтверждённого provider video не сохраняются.

Проверки (команда/сценарий, фактический результат): `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1` — успешно, 0 warnings/0 errors; `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1` — успешно, 19/19. Release-приложение запущено в скрытом окне: процесс отвечал; затем завершён процесс, созданный только для smoke-проверки.

Данные и совместимость: используется существующая SQLite-схема 1 в `%LocalAppData%\NexsusVKVideo\data`. UI не пишет в Git, не хранит tokens/cookies и не запрашивает учётные данные VK.

Откат (commit/порядок, резервная копия, проверка): `git revert <commit>` этого изменения, затем restore/build/test. Данные остаются в пользовательской SQLite-базе; при необходимости удалить их нужно только явной пользовательской командой в будущем экране Settings.

Ограничения: ручная визуальная проверка tab-order, resize, DPI и интерактивных кликов недоступна через текущую среду автоматизации. Search, авторизация, настройки темы и очистка WebView2-кэша ещё не реализованы.
