# Встроенный официальный сайт VK Video

Цель: дать пользователю пользоваться каталогом, поиском и авторизацией официального сайта VK Video внутри NexsusVKVideo без вставки ссылок и без запуска отдельного браузера.

Базовый commit: `87b3aff`.

Затронутые компоненты: WPF navigation и WebView2 host, VK navigation allowlist в Infrastructure, unit-тесты и документация состояния.

Результат: пункт «VK Video» открывает `https://vkvideo.ru/` во встроенном WebView2 на основной площади окна. Встроенный браузер разрешает только HTTPS-навигации к доменам `vkvideo.ru`, `vk.ru` и `vk.com` с их поддоменами; popup-навигация VK остаётся в том же окне. Учётная сессия принадлежит профилю WebView2 и очищается существующей командой Settings после перезапуска. NexsusVKVideo не получает пароль, токен или cookie и не обходит ограничения сайта.

Проверки: `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1` — успешно, 0 warnings/0 errors; `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1` — успешно, 32/32. Ручная проверка нужна с доступом к сайту VK Video: загрузка, поиск, вход и popup-навигация. Автоматическая проверка сайта не выполнена: в окружении разработки сетевой proxy направляет запрос на недоступный `127.0.0.1:9`.

Миграция/совместимость: миграции SQLite отсутствуют. Существующие локальные история и избранное не изменяются.

Откат: `git revert <commit>` для commit этого изменения; затем повторить build и test. Для выхода из сессии VK использовать существующую очистку данных плеера в Settings.
