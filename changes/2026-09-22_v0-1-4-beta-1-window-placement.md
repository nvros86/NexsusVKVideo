# v0.1.4-beta.1 — состояние окна

## Что изменено
- Размер, позиция и развёрнутое состояние записываются при закрытии в локальный JSON-файл.
- При старте валидируются числовые значения и сохраняется видимый край окна в пределах виртуального рабочего стола.
- Повреждённый или недоступный файл состояния игнорируется; приложение использует безопасные стартовые размеры.

## Проверка
- `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1`
- `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1`
- Ручной smoke перед выпуском: normal/maximized, второй монитор, отключение второго монитора, отрицательные координаты и повреждённый JSON.

## Ограничения и откат
- JSON не содержит данные VK, cookies или историю; удаление файла возвращает стартовый размер окна.
- Откат: revert коммита; при необходимости удалить только `%LocalAppData%\NexsusVKVideo\window-placement.json`.
