# v0.1.7-beta.1 — интеграция с Windows

## Изменение

- Стиль системного заголовка заново применяется при изменении пользовательских настроек Windows.
- При смене конфигурации дисплеев обычное окно удерживается в видимой части виртуального рабочего стола.
- При `Resume` экран восстановления повторяет запуск браузера, только если он уже показывал ошибку.

## Границы

- Рабочая страница VK Video не перезагружается после сна, поэтому приложение не вмешивается в активное воспроизведение или форму сайта.
- Высокая контрастность не переопределяется приложением.

## Проверка

- Требуется build и автоматические тесты решения.
- Ручной smoke на Windows: переключить светлую/тёмную тему, отключить дополнительный монитор, перевести ПК в сон при отображённой ошибке загрузки.
