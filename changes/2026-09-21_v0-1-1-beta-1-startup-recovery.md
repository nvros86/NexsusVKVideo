# v0.1.1-beta.1 — восстановление запуска

## Что изменено
- Экран ошибки WebView2 получил кнопку повторной загрузки и кнопку перехода на официальную страницу Microsoft Edge WebView2 Evergreen Runtime.
- После успешной навигации VK Video экран ошибки скрывается.
- Добавлен версионируемый план следующих пользовательских улучшений.

## Проверка
- Выполнены: `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1` и `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1`.
- Перед публикацией обязательны ручные smoke-сценарии: отсутствие Runtime, ошибка сети, Retry, успешная загрузка, keyboard focus, resize и DPI.

## Ограничения и откат
- Переход за Runtime открывается в системном браузере и не устанавливает компоненты автоматически.
- Откат: revert коммита версии; пользовательские данные WebView2 не изменяются.
