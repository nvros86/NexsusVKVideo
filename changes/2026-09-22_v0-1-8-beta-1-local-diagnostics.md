# v0.1.8-beta.1 — локальная диагностика

## Изменение

- Добавлено сочетание `Ctrl+Shift+D`, показывающее версию NexsusVKVideo, WebView2 Runtime и Windows.
- Отчёт копируется в буфер обмена только после отдельного выбора пользователя.

## Приватность

- Приложение не создаёт файл отчёта и не отправляет телеметрию.
- В отчёт намеренно не включаются URL, история просмотра, cookies, данные входа, токены и локальные пути.

## Проверка

- Требуется build и автоматические тесты решения.
- Ручной smoke: вызвать `Ctrl+Shift+D`, проверить состав отчёта и отменить либо подтвердить копирование.
