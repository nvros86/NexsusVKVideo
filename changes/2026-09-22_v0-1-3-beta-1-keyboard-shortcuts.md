# v0.1.3-beta.1 — горячие клавиши

## Что изменено
- Добавлены сочетания Alt+Left/Right для истории, F5 и Ctrl+R для обновления, Ctrl+Plus/Minus для масштаба, Ctrl+0 для возврата к 100%.
- Масштаб ограничен 50–300%, сочетания обрабатываются только после создания WebView2.

## Проверка
- `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1`
- `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1`
- Ручной smoke перед выпуском: страница VK, история с двумя переходами, оба варианта обновления, плюс/минус с основной и цифровой клавиатуры, возврат к 100% и отсутствие перехвата обычного ввода.

## Ограничения и откат
- Горячие клавиши не сохраняют пользовательский масштаб между перезапусками; это будет решаться только вместе с версией состояния окна.
- Откат: revert коммита; пользовательские данные WebView2 не изменяются.
