# Стартовый размер окна в рабочей области экрана

Цель: исключить запуск NexsusVKVideo за границами доступной рабочей области небольшого экрана.

Базовый commit: `0d9b499`.

Затронутые компоненты: XAML и code-behind главного WPF-окна.

Результат: базовый размер изменён с 1600×1000 на 1280×800 DIP. Перед показом окна его минимальные, текущие и максимальные размеры ограничиваются рабочей областью `SystemParameters.WorkArea` с отступом 16 DIP. При достаточном пространстве нормативный минимум 960×640 сохраняется.

Проверки: `dotnet build NexsusVKVideo.sln -c Release --no-restore -m:1` — успешно, 0 warnings/0 errors; `dotnet test NexsusVKVideo.sln -c Release --no-build -m:1` — успешно, 26/26. Ручная проверка требуется на экранах 1280×800, 960×640 и с масштабом DPI 150%.

Миграция/совместимость: данных и настроек не изменяет.

Откат: `git revert <commit>` для commit этого изменения; затем повторить build и test.
