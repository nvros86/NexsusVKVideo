# v0.2.0-beta.1 — безопасное обнаружение обновлений

## Изменение

- `Ctrl+Shift+U` читает публичный список GitHub Releases проекта и находит более новую версию beta-канала.
- Если версия найдена, пользователь может открыть только её страницу GitHub в системном браузере.

## Модель доверия

- Приложение обращается только к HTTPS API GitHub для фиксированного публичного репозитория `nvros86/NexsusVKVideo`.
- Автоматические скачивание, запуск и замена EXE отсутствуют: до цифровой подписи это небезопасно.
- Запрос не содержит идентификатора пользователя, cookies или токенов VK.

## Проверка

- Требуется build и автоматические тесты решения.
- Ручной smoke: вызвать `Ctrl+Shift+U` при доступной сети; убедиться, что при новой версии открытие GitHub требует подтверждения.
