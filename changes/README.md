# Изменения и rollback
Один файл YYYY-MM-DD_short-slug.md на логическое изменение; начать до существенной правки, завершить после проверки.
Обязательные поля: цель, базовый commit (или «initial import»), затронутые компоненты, результат, проверки и их статус, миграция/совместимость, конкретный откат.
Не хранить копии исходников и полные diff: для этого Git.
Откат опубликованного обычного commit: git revert <sha>, затем build/tests. Merge требует выбора mainline и отдельной проверки.
Не использовать reset --hard или force push для общего репозитория.
При изменении данных сначала резервная копия, затем проверенный restore/downgrade. Revert кода сам по себе не откатывает данные.
