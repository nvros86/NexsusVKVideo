# Changelog
## Unreleased

## 0.2.1-beta.1 — 2026-09-22
- Исходники beta-релиза теперь включают MIT License, публичный скриншот работающего приложения, правила поддержки и безопасности, а также автоматическую проверку обновлений зависимостей.
- Функции воспроизведения и работы сайта VK Video не менялись; это выпуск готовности открытого проекта и распространения.

## 0.2.0-beta.1 — 2026-09-22
- Добавлена проверка публичных GitHub Releases beta-канала по `Ctrl+Shift+U`.
- При наличии более новой версии приложение только предлагает открыть её страницу на GitHub в системном браузере. Неподписанные файлы не скачиваются и не заменяются автоматически.

## 0.1.8-beta.1 — 2026-09-22
- Добавлена локальная диагностика по `Ctrl+Shift+D`: версия приложения, версия WebView2 Runtime и версия Windows.
- Отчёт не отправляется по сети; его можно скопировать в буфер обмена только по явному выбору. URL, история, cookies, учётные данные и пути к файлам в него не входят.

## 0.1.7-beta.1 — 2026-09-22
- Заголовок NexsusVKVideo применяет изменение цветовой схемы Windows без перезапуска приложения.
- При изменении мониторов обычное окно ограничивается доступной виртуальной рабочей областью.
- После пробуждения Windows экран восстановления автоматически повторяет инициализацию только если до сна была показана ошибка; успешно работающая страница VK не перезагружается.

## 0.1.6-beta.1 — 2026-09-22
- Загрузки из WebView2 разрешены только для защищённых доменов VK; остальные источники отменяются до появления системного диалога сохранения.
- Внешние HTTPS-ссылки больше не открываются неявно: пользователь может подтвердить их запуск только в системном браузере. Неподдерживаемые схемы и HTTP блокируются.

## 0.1.5-beta.1 — 2026-09-22
- Добавлено стандартное сочетание `Ctrl+Shift+Delete`: с явным подтверждением оно планирует удаление локального профиля WebView2 на следующий запуск.
- Очистка удаляет cookies, активный вход и локальные настройки сайта VK Video; пароли и токены приложение не читает и не передаёт.

## 0.1.4-beta.1 — 2026-09-22
- Окно NexsusVKVideo сохраняет размер, позицию и развёрнутое состояние между запусками.
- Восстанавливаемая позиция ограничивается виртуальным рабочим столом, поэтому после изменения набора мониторов часть окна остаётся доступной.

## 0.1.3-beta.1 — 2026-09-22
- Добавлены стандартные горячие клавиши WebView: `Alt+←/→`, `F5`/`Ctrl+R`, `Ctrl++`, `Ctrl+-` и `Ctrl+0`.
- Масштаб страницы ограничен диапазоном 50–300% и не требует модификации страниц VK Video.

## 0.1.2-beta.1 — 2026-09-21
- Добавлен воспроизводимый Inno Setup installer для Windows x64: per-user установка, ярлыки в меню «Пуск» и на рабочем столе, а также uninstall.
- Установщик проверяет наличие Microsoft Edge WebView2 Evergreen Runtime и, если он отсутствует, предлагает открыть официальную страницу Microsoft после установки приложения.

## 0.1.1-beta.1 — 2026-09-21
- Добавлен экран восстановления запуска: повторная попытка загрузки VK Video и переход к официальной установке Microsoft Edge WebView2 Evergreen Runtime.
- Ошибка загрузки больше не оставляет пользователя без доступного действия; после успешной навигации экран ошибки автоматически скрывается.

## 0.1.0-beta.1 — 2026-09-19
- NexsusVKVideo опубликован как минимальная WebView2-оболочка официального сайта VK Video.
- Приложение открывает только защищённые домены VK и удерживает popup-навигацию VK в том же окне.
- Добавлены системная строка заголовка Windows, значок NexsusVKVideo и поддержка полноэкранного видео из WebView2.
- Публикация для Windows x64 создаётся одним self-contained `.exe`.
- Для запуска необходим Microsoft Edge WebView2 Evergreen Runtime; каталог, поиск, вход и доступность видео определяются сайтом VK.
