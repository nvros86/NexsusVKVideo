# Changelog
## Unreleased

## 0.1.1-beta.1 — 2026-09-21
- Добавлен экран восстановления запуска: повторная попытка загрузки VK Video и переход к официальной установке Microsoft Edge WebView2 Evergreen Runtime.
- Ошибка загрузки больше не оставляет пользователя без доступного действия; после успешной навигации экран ошибки автоматически скрывается.

## 0.1.0-beta.1 — 2026-09-19
- NexsusVKVideo опубликован как минимальная WebView2-оболочка официального сайта VK Video.
- Приложение открывает только защищённые домены VK и удерживает popup-навигацию VK в том же окне.
- Добавлены системная строка заголовка Windows, значок NexsusVKVideo и поддержка полноэкранного видео из WebView2.
- Публикация для Windows x64 создаётся одним self-contained `.exe`.
- Для запуска необходим Microsoft Edge WebView2 Evergreen Runtime; каталог, поиск, вход и доступность видео определяются сайтом VK.
